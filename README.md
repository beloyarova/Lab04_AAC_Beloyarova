ИТОГОВЫЙ ВОПРОС

Environment.ProcessorCount показывает число логических процессоров которые видит операционная система, а не число физических ядер. Благодаря технологии Hyper-Threading каждое из 4 физических ядер может выполнять два потока одновременно, поэтому система видит 8 логических процессоров. Значит, значение 8 правильное и не противоречит наличию 4 физических ядер

КОНТРОЛЬНЫЕ ВОПРОСЫ

1. Что показывает Environment.ProcessorCount?

Количество логических процессоров, доступных текущему процессу

2. Чем физическое ядро отличается от логического процессора?

Физическое ядро реальный блок процессора с вычислительными устройствами. Логический процессор то, как ядро представлено ОС

3. Почему увеличение количества потоков может увеличить загрузкуCPU?

Каждый вычислительный поток может занять отдельный логический процессор, и чем больше процессоров работает, тем выше общая загрузка

4. Почему после некоторого количества потоков загрузка не обязательно продолжает расти?

Все логические процессоры уже заняты. Лишние потоки только ждут очереди, а ОС переключает их по очереди

5. Почему частота процессора может изменяться во время работы?

Процессор динамически меняет частоту в зависимости от нагрузки, температуры, лимитов мощности и настроек электропитания так он экономит энергию и не перегревается
